# 잇다(It-Da)

춘천 고령층을 위한 비시각적 AI 버스 동행 앱 프로토타입입니다.
휴대폰을 주머니에 넣은 채로도 버스를 타고 내릴 수 있도록, 앱이 먼저 음성과 진동으로 알려 줍니다.

- 노선: 춘천 3번 버스 후평동종점 → 명동입구 (정류장 순서는 국토교통부 공공데이터 기준)
- 버스 위치와 GPS는 아직 실시간으로 연동하지 않고 시뮬레이션합니다.
- 음성 안내·음성 인식·진동은 안드로이드 크롬에서 가장 잘 동작합니다.

## 실행

```bash
npm install
npm run dev
```

`main` 브랜치에 올리면 GitHub Actions가 GitHub Pages로 자동 배포합니다.
